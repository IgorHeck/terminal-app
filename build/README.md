# Build resources

Coloque aqui os arquivos de recursos usados pelo electron-builder:

- `icon.ico` — ícone Windows (256x256, formato ICO multi-resolução)
- `icon.png` — ícone fonte (512x512 PNG, gerado automaticamente pelo electron-builder para Mac/Linux)

O electron-builder procura automaticamente `icon.ico` para Windows e `icon.png` para Mac/Linux.
Se os arquivos não existirem, o instalador usa o ícone padrão do Electron.
